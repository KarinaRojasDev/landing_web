Proyectos Destacados

LiterAlura

Aplicación en Java con Spring Boot que permite buscar libros usando la API de Gutendex, registrar información de libros y autores en PostgreSQL, y consultar los datos por distintos criterios como idioma, año de nacimiento de los autores y descargas.

Funcionalidades principales:

Aplicación de consola que permite consultar y gestionar información de libros y autores obtenida desde una API externa, almacenando posteriormente los datos en una base de datos para su consulta.

  • Buscar libros en la API de Gutendex y registrarlos en la BBDD
  • Listar libros y autores registrados
  • Filtrar autores vivos en un año específico y libros por idioma
  • Mostrar información de descargas y detalles de cada libro
Tecnologías:

El proyecto fue desarrollado con el ecosistema de Spring para crear una aplicación estructurada con persistencia de datos y consumo de APIs externas.

Java 17+ · Spring Boot 3 · Spring Data · JPA/Hibernate · PostgreSQL · Gutendex API · Maven

NeoFichaje

NeoFichaje es una aplicación Android diseñada para la gestión de fichajes, vacaciones y documentos en entornos laborales. Permite a los empleados registrar sus jornadas, solicitar permisos y consultar documentos, mientras que los administradores supervisan y gestionan su equipo de manera eficiente desde cualquier lugar.

Tecnologías:

La aplicación fue desarrollada para Android utilizando Kotlin y XML, siguiendo las buenas prácticas de desarrollo en Android Studio. Se integraron distintos servicios de Firebase para la gestión de usuarios, almacenamiento seguro de documentos y base de datos en la nube.

Kotlin · XML · Android Studio · Firebase Authentication · Firestore · Cloud Storage · Google Sign-In · MaterialCalendarView

Funcionalidades principales:

La aplicación permite a los empleados gestionar su jornada laboral, solicitudes y documentos desde el móvil, mientras que los administradores pueden supervisar y aprobar las diferentes acciones del personal.

  • Fichaje con geolocalización
  • Registro y login seguro con correo y Google
  • Gestión de vacaciones y permisos
  • Consulta y descarga de documentos (contratos, nóminas)
  • Panel de administrador para control de empleados
  • Historial de actividad por usuario
